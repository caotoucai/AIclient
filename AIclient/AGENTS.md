# AIclient 项目续接入口

在本目录继续工作前，先读取 [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)，再根据任务读取 [ARCHITECTURE.md](ARCHITECTURE.md) 和相关源码。

- 新功能与修改默认在 `AIclient` 内完成；根目录旧 AT 客户端供参考。
- 所有 ComboBox 只允许选择列表项，不开启文本编辑；设备绑定/参数界面参考根目录对应 Addins 模块。Codex 与测试 Skills 集中在独立 AI 设置页，ADB 归设备配置，台架背景独立。
- ADB1 / ADB2 是中性设备编号，允许两台都是手机。不得恢复为强制车机/手机角色。
- Codex 使用本机 PowerShell + CLI 调用，沿用已有登录；具体实现见架构文档。
- 区分已实现能力、软件替身验证和真实硬件验收，不将模拟结果写成实机通过。
- 实机测试应按用户设置积累弹窗、阻塞和状态过渡等有证据的经验，并使用应用实际测试知识库；不能为了隔离运行产物而自行关闭自动经验。经验应包含触发条件、处理原则、验证结果及来源，不记录固定点击坐标。
- 实现变更后同步相关架构/使用说明与续接记录，保留用户已有配置和 evidence。

这些入口文件是磁盘上的项目记录；继续工作时应核对实际源码和验证产物，不依赖上一轮对话是否仍在上下文中。
